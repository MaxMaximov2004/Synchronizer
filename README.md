# Synchronizer
Данный проект представляет собой настольную программу - синхронизатор локальной папки и удалённой. В качестве удалённой папки мы рассматриваем как папку на физическом носителе, так и в облаке.
По стеку у нас .Net 8, сам проект состоит из ядра (Synchronizer_Core) в котором находятся основные сущности - что синхронизируем и как синхронизируем, а также реализация под конкретную платформу - в данном случае под Windows (Win_Synch написан на WPF). 

## Сущности проекта:

| Полное имя                                    | Назначение                                                                                                                     |
| --------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------ |
| Synchronizer_Core.Vault_Manager.Vault_Manager | Базовый абстрактный класс инкапсулирующий работу с конкретным хранилищем: реестр, отдельные файлы и тд.|
|                                               |                                                                                                                                |
| Synchronizer_Core.Synch.ISynch                | Интерфейс предоставляющий необходимые методы, для объекта который занимается синхронизацией.                                   |
|                                               |                                                                                                                                |
